   -> Связывание локальной папки с репозиторием на сайте GitHub под именем origin.

9. git push -u origin main
   -> Первая отправка коммитов на GitHub (шаг 14-15 лабы). Флаг -u запоминает ветку.

10. git pull origin main
    -> Скачивание изменений с GitHub (шаг 19 лабы). На сайте добавили строку "Дополнительный тест.", pull влил её в локальный файл.

    -> Просмотр списка коммитов в одну строчку (шаг 20 лабы). Показало 3 коммита.
